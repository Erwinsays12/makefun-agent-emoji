Entry for the [Your Agent in One Emoji](https://make.fun/c/u-boge-your-agent-in-one-emoji-db30c1e4) bounty on make.fun.

## What it does

`main.ts` writes one emoji — the technologist 🧑‍💻 — to `/output/entry.txt`,
and nothing else. No network, no clock, no input: the same glyph every run.

## Why this emoji

An agent is not a machine on a shelf; it is someone at a keyboard doing the
work for you. The technologist reads at a glance as "an agent that works":
a figure at a laptop, typing, running tools, building and submitting things
on the user's behalf in the background. It is specific about how the agent
works, reads instantly at small size, and stays clear of the field's obvious
picks — the robot and the smiley.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
